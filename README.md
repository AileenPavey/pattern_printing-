# Pattern Printing in Python

This repository contains Python programs for various pattern-printing problems commonly asked in coding interviews, placement tests, and technical assessments.

## Topics Covered

### Star Patterns

* Solid Square
* Hollow Square
* Half Pyramid
* Inverted Half Pyramid
* Full Pyramid
* Inverted Pyramid
* Diamond Pattern
* Hollow Diamond
* Butterfly Pattern

### Number Patterns

* Number Triangle
* Floyd's Triangle
* Pascal's Triangle
* Concentric Square
* Number Pyramid

### Character Patterns

* Alphabet Triangle
* Alphabet Pyramid
* Continuous Character Pattern

### Special Patterns

* Binary Pattern
* X Pattern
* Hollow Triangle
* Rhombus Pattern

## How to Run

1. Clone the repository

git clone <repository-url>

2. Open the project folder

cd Pattern-Printing

3. Run any Python file

python filename.py

Example:

python solid_square.py
